Model Context Protocol (MCP) is a [standard protocol](https://modelcontextprotocol.io/) created by Anthropic that defines how AI models connect to external tools and services. TypingMind supports MCP natively, letting you connect to any MCP-compatible server — whether it's a remote service accessible over HTTPS or a local server running on your machine via `npx`, `uvx`, or Docker. Once connected, an MCP server appears as a regular plugin in TypingMind and can be used in any conversation.

## Connect to remote MCP servers via the MCP Store

TypingMind's **MCP Store** contains pre-configured connectors for popular third-party services. Connecting through the store is the fastest way to get started.

<Steps>
  <Step title="Open the MCP Store">
    Go to **Plugins** → **MCP Store** in TypingMind.
  </Step>
  <Step title="Find your server and add a connection">
    Browse or search for the service you want to connect. Click **Add connection** next to it.
  </Step>
  <Step title="Authenticate">
    Click **Connect** and follow the authentication steps. Most services use OAuth, so you'll be redirected to log in with your account.
  </Step>
  <Step title="Use the connection in chats">
    Once connected, the MCP server appears as a plugin you can enable in any conversation — just like any other TypingMind plugin.
  </Step>
</Steps>

## Add a custom MCP connector

If the service you need isn't in the MCP Store, you can add it manually:

<Steps>
  <Step title="Click Add custom connector">
    In the MCP Store, click **Add custom connector**.
  </Step>
  <Step title="Fill in the server details">
    Enter the MCP server URL and any required configuration. Check the documentation from the service provider to get their MCP server URL, authentication requirements, and other connection details.
  </Step>
  <Step title="Connect and authenticate">
    Save the connector and follow any authentication steps required by the service.
  </Step>
</Steps>

## Customize active tools

Each MCP server exposes a set of tools. You can enable or disable individual tools from a connected server — useful when you want to limit the AI's access to only the tools you actually need, or to disable any destructive operations.

To toggle tools on or off, open the MCP connection settings and use the toggle switches in the tools list.

<Warning>
  Review the available tools from any MCP server before enabling them in sensitive workflows. Disable tools you don't need, especially those that write, delete, or modify data.
</Warning>

## Long-running sessions and token refresh

TypingMind automatically manages MCP sessions and token refresh:

- **Sessions** are managed per chat (and per user in the Team version). A new MCP session is created for each user and for each chat they create.
- **Sessions expire** after 5 minutes of inactivity and are handled automatically in the background.
- **Access tokens** are refreshed automatically if the MCP server supports the [OAuth refresh token flow](https://www.oauth.com/oauth2-servers/making-authenticated-requests/refreshing-an-access-token/). If refresh tokens are not supported, you will need to re-authenticate when your access token expires.

TypingMind supports **stateful MCP servers**, maintaining persistent sessions so the server can remember context between tool calls within the same chat.

## Multiple connections and OpenID support

You can add multiple connections to the same MCP server. This is useful when you need to use multiple accounts of the same service simultaneously.

For example, if you have two Notion accounts, add the Notion MCP connector twice and authenticate each with a different account. Both connections appear as separate plugins in TypingMind.

If the service's OAuth server supports **OpenID**, TypingMind will display the account name and profile information next to each connection so you always know which account is active.

## Use a custom OAuth client

By default, TypingMind registers itself with MCP servers using OAuth 2.0 Dynamic Client Registration ([RFC 7591](https://datatracker.ietf.org/doc/html/rfc7591)). If the service provider doesn't support dynamic client registration, you can supply your own OAuth client credentials:

Go to **Plugins** → **MCP Store** → **Add custom connector** → **Advanced options** → **OAuth Client**.

**Redirect URLs for OAuth client setup:**

For the **Personal version:**
- Main: `https://www.typingmind.com/oauth/callback`
- Backup: `https://www.typingmind.com`

For the **Team version**, your unique redirect URL is displayed in the OAuth Client section.

Add both redirect URLs to your OAuth app's authorized redirect URIs.

## MCP connector options

When you connect to a remote MCP server for the first time, TypingMind asks you to select a connector. There are two options:

<Tabs>
  <Tab title="TypingMind Cloud (recommended)">
    The easiest option — no setup required. TypingMind Cloud acts as the intermediate connector between your browser and the MCP server.

    You need to sign up for a free TypingMind Cloud account to use this option (required to prevent spam on the cloud infrastructure).
  </Tab>
  <Tab title="Private MCP Connector">
    A self-hosted connector you run on your local machine or private server. Use this option when:
    - You need to connect to a local MCP server running on your device.
    - You prefer not to route traffic through TypingMind's cloud infrastructure.
    - You have specific security or compliance requirements.

    See [Use MCP with Private MCP Connector](/model-context-protocol-mcp-in-typingmind/use-mcp-with-private-mcp-connector) for setup instructions.
  </Tab>
</Tabs>

<Note>
  The MCP Connector (both cloud and private) is only required in the **Personal version** of TypingMind. The Team version handles MCP connections differently.
</Note>
