# Side Chat (Ask or Quote)

The **Side Chat** feature allows you to dive deeper into specific parts of an AI response without interrupting your main conversation.

## **How It Works**

1. **Select or highlight a section** of the AI’s response.
2. Choose **“Ask” or “Quote”** option 

![image.png](side-chat-(ask-or-quote)/image.png)

## **Side chat or Ask option**

**Side Chat or Ask** lets you create a focused mini-thread based on a selected portion of the AI’s message. 

When you highlight any specific part of the AI response and select Ask, this opens up a separate chat window so you can ask any questions about specific part within the AI response without being saved to the main conversation branch. This allows you to:

- Clarify a particular idea
- Ask follow-up questions
- Explore additional context

All while keeping your primary chat clean and easy to follow.

![image.png](side-chat-(ask-or-quote)/image%201.png)

## **Quote option**

When you highlight a specific part of the AI response and select Quote, the highlighted part will appear on the input box so you can add you request regarding that specific parts. This allows you to:

- Give targeted feedback
- Correct details
- Request revisions or improvements to a certain part of the response

This ensures clearer communication and more accurate refinements.
