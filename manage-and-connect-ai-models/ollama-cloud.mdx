title: "Ollama Cloud"
---

Set up and use Ollama Cloud models on TypingMind.

## 1. Get Ollama Cloud API key

- Sign into [Ollama](https://signin.ollama.com/) 
- Go to [Keys](https://ollama.com/settings/keys) and click Add API Key 
- Copy the API key

<Frame>
  ![Ollama Cloud Api Key](/images/ollama-cloud-api-key.webp)
</Frame>

## 2. Set up Ollama Cloud in TypingMind

- Go to [typingmind.com](http://typingmind.com)
- Select Models → API key tab to enter the coped API key for Ollama Cloud

Switch back to Models tab → Select Ollama Cloud to enable the Ollama Cloud models you want to chat with.
