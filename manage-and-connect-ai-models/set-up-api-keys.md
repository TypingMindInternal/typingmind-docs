- [OpenRouter](/manage-and-connect-ai-models/openrouter)

- [xAI](/manage-and-connect-ai-models/xai-\(grok-ai\))
- [Z.ai](http://Z.ai)
- and more to come!

You can add or manage API keys as following:

- Click **Models** in the left sidebar, then click the gear icon next to the AI provider you want to connect with.
- or Click **Models** in the left sidebar, then switch to API keys tab to enter your API keys.

## For other models

In case you want to use chat models not available within our provided list above, such as models from Azure Foundry, HuggingFace, etc. you can completely set up these chat models on TypingMind by following the steps below:

- Open the Model settings on the left side panel.
- Click on **Add Custom Models**.
- Set up the custom models for:
  - [Azure OpenAI](https://docs.typingmind.com/chat-models-settings/use-azure-openai)
  - [Minimax](/manage-and-connect-ai-models/minimax)
  - [Jina](/manage-and-connect-ai-models/jina-deep-research)
  - [LMStudio](/manage-and-connect-ai-models/lmstudio-\(phi-3-llama-3-falcon-gemma-gpt-neo-x\))

<Tip>
  More guides can be found at [https://docs.typingmind.com/manage-and-connect-ai-models](https://docs.typingmind.com/manage-and-connect-ai-models)
</Tip>
