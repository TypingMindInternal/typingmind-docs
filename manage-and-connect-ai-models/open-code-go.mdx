Set up and use OpenCode Go models on TypingMind.

## 1. Get OpenCode API key

Sign in to [**<u>OpenCode Zen</u>**](https://opencode.ai/auth), subscribe to Go, copy your API key and save to safe place.

<Frame>
  ![Opencode Api Key](/images/opencode-api-key.webp)
</Frame>

## 2. Set up OpenCode Go in TypingMind

- Go to [typingmind.com](http://typingmind.com)
- Select Models → API key tab to enter the coped API key for OpenCode Go

Switch back to Models tab → Select OpenCode Go to enable the OpenCode Go models you want to chat with.
