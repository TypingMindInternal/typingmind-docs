Set up and use Vercel Gateway models on TypingMind!

## Step 1: Get Vercel Gateway API key

Go to [https://vercel.com/ai-gateway](https://vercel.com/ai-gateway) and click Create an API key (Login/Signup if you haven't logged in yet)

<Frame>
  ![Vercel 1](/images/vercel-1.webp)
</Frame>

On the Vercel dashboard, click on API keys → Create API key to create a new API key:

<Frame>
  ![Vercel Api Key](/images/vercel-api-key.webp)
</Frame>

## Step 2: Use Vercel Gateway models on TypingMind

- Go to [typingmind.com](http://typingmind.com)
- Select Models → API key tab to enter the coped API key for Vercel

Switch back to Models tab → Select Vercel to enable the Vercel models you want to chat with.
