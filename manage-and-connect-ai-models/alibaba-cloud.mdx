Use Qwen models from Alibaba Cloud in TypingMind!

## Step 1. Sign up for an Alibaba Cloud account

Go to [Alibaba Cloud](https://account.alibabacloud.com/login/login.htm) and log in or sign up for an account.

Follow the steps on screen to set up your account.

## Step 2. Get Alibaba Cloud API key

1. Go to the [Alibaba Cloud Model Studio console](https://modelstudio.console.alibabacloud.com/cn-hongkong?spm=a2c63.p38356.0.0.79ea422fSFZ8QS) and switch the region to **US** from the upper-right corner if you are currently using another region _(only the US region is currently supported.)_
2. On the **Dashboard** tab, choose **API Key** from the left-side navigation pane and then click **Create API Key**.
3. In the dialog box that appears, configure the following information and click **OK**:
   - **Workspace**: We recommend that you select the default workspace.
   - **Description**: Enter a description to identify the API key's purpose.
4. After the key is created, the dialog box displays the full API key. Immediately copy or download and save it in a secure location.

<Frame>
  ![Alibaba Cloud Api](/images/alibaba-cloud-api.png)
</Frame>

## Step 3. Enter Alibaba Cloud API key to TypingMind

Go to **TypingMind → Models → API Keys**, then find **Alibaba Cloud API Key** and enter your API key.

Switch back to models tab → select Alibaba Cloud as the provider and enable the model you want to chat with.

<Frame>
  ![Alibaba Models](/images/alibaba-models.webp)
</Frame>

<Info>
  **For TypingMind License users:**

  Currently, Alibaba Cloud only supports browser-based API requests for resources hosted in the **US region**. If your API key or endpoint is configured in another region, the request may be blocked by CORS, which can result in the error you're seeing.

  You can resolve this in one of two ways:

  1. If you want to keep using the endpoint in your current region, you’ll need to manually configure a proxy for this model on your end.
  2. Switch your Alibaba Cloud Model Studio region to the US and create a new API key there.
</Info>
