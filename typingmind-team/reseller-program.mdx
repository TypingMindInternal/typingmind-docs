## What is TypingMind Reseller Program?

Generative AI is transforming how businesses work around the world. TypingMind helps businesses by providing an AI platform where everyone in the company can access the latest generative AI models via a unified and secure chat interface.

We collaborate with Resell Partners to deploy TypingMind as the technical platform for businesses — especially in local markets where companies don't have much context into the latest generative AI technologies. Our Reseller Program is designed to be profitable for partners, with successful resellers already operating in Germany, Canada, Thailand, and more.

You are a good fit for the Reseller Program if you:

- Have experience in the local market and access to local businesses
- Understand generative AI and related technologies: prompt engineering, AI agents, RAG, plugins, API integrations, etc.
- Have a solid understanding of the TypingMind system and its features
- Can provide added-value services on top of TypingMind, such as:

## Choose your reselling structure

### 1. Resell type: Seat vs. Instance

**Seat resell** — Create one instance under your brand and sell individual seats to customers. Customers only access the end-user interface, not the Admin panel.

**Instance resell** — Create a private instance for each customer under their brand, help them set up and manage it. Optionally grant them Admin panel access.

### 2. AI provider & API cost

**Option 1 — Reseller pays (recommended):** You pay for the AI providers and configure the instance using your own API keys (OpenAI, Anthropic, or Google AI).

**Option 2 — Customer pays:** You set up the instance, then the customer uses their own API keys and pays the AI provider directly.

### 3. Deployment

| Option | Details |
| --- | --- |
| **Cloud host (recommended)** | Hosted in US (Virginia) or EU (Frankfurt) data centers. Maximum convenience with seamless software updates. |
| **Self-host on customer infrastructure** | Deployed to the customer's own servers. Requires a technical team to set up and maintain. More info at [custom.typingmind.com/self-host](https://custom.typingmind.com/self-host). |
| **Self-host on your infrastructure** | You host TypingMind privately and provide access to customers. You are responsible for hosting and protecting customer data. |

We always recommend cloud hosting when possible — it's easier to deliver updates and provide support, with industry-standard security and privacy.

### 4. Value-added services

TypingMind acts as a technical partner. We encourage you to add value for customers by offering:

- Creating AI agents, prompts, and custom workflows
- Bundling the platform with your own consulting or training services
- Providing tailored solutions or support for specific customer needs
