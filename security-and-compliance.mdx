TypingMind is designed with privacy as a default. The core application stores your data locally in your browser and sends API requests directly to AI providers — your data does not pass through TypingMind's servers unless you explicitly opt in to cloud features. This page explains the security model, your data rights, and links to the relevant compliance documentation.

<Note>
  TypingMind is GDPR compliant. If you have a contract with TypingMind, you can request security-related documents via the [Trust Center](https://trust.typingmind.com/).
</Note>

## Local-first data model

By default, TypingMind operates as a fully local application:

- **API keys** are stored in your browser's local storage, not on TypingMind's servers
- **Chat history** is stored locally per browser
- **AI API requests** go directly from your browser to the AI provider (OpenAI, Anthropic, etc.) — no TypingMind proxy
- **Search queries** are sent directly from your browser to the search engine API

This means TypingMind's servers cannot see your conversations, your API keys, or your queries by default.

<Tip>
  To confirm that API requests go directly to OpenAI and not through any TypingMind backend, open your browser's Developer Tools, go to the Network tab, and inspect outbound requests when you send a message. You will see direct requests to the AI provider's endpoint.
</Tip>

## API key security

Your API key is the most sensitive credential in your TypingMind setup. Here is how it is handled:

- Stored in browser local storage on your device only
- Never transmitted to TypingMind's servers
- OpenAI's own policy permits API keys to be stored locally in user devices

### Optional API key encryption

TypingMind offers additional protection for your API key using AES encryption:

1. Click the **API Key** button in the sidebar.
2. Select **Encrypt API key**.
3. Set a password. Your key is encrypted using the open-source CryptoJS AES implementation.

<Warning>
  If you enable encryption and forget the password, your API key cannot be recovered from within TypingMind. You would need to re-enter the key with a new password.
</Warning>

The encryption is performed entirely on your device. TypingMind's servers are not involved in the encryption or key storage process. Chat messages, prompts, agents, and other elements are stored using standard browser local storage, which may or may not include OS-level encryption depending on your browser and device.

## TypingMind Cloud security

TypingMind Cloud is an optional service for syncing and backing up your data across devices. If you enable it:

- All communication with TypingMind Cloud servers uses **HTTPS encryption** in transit
- Data is stored in an **AWS-hosted database encrypted at rest**
- A session cookie is used to maintain your logged-in state; it expires after 30 days of inactivity
- You can opt out at any time by signing out of your TypingMind Cloud account

### What TypingMind Cloud stores

When cloud sync is enabled, the following data is stored on TypingMind's servers:

- Chats and message attachments
- Prompts, AI agents, and plugins
- API keys and license key (if sync is enabled for these)
- Preferences, settings, and custom models

You can control which categories are synced via **Settings → Cloud Sync & Backup → Sync Settings**.

## GDPR compliance

TypingMind complies with the General Data Protection Regulation (GDPR). Key points:

- You can request deletion of your data at any time by contacting support@typingmind.com
- Data processing is described in detail in the [Data Processing Agreement](/security-and-compliance/data-processing-agreement)
- For the full statement, see the [GDPR Statement](/security-and-compliance/gdpr-statement)

## Data usage and model training

TypingMind does not use your chat data for model training. Your conversations are not shared with AI model providers for training purposes beyond what each provider's own policies allow (for example, OpenAI's API data usage policy for API customers, which differs from their consumer product policies).

See the [Data Usage and Model Training Policy](/security-and-compliance/data-usage-and-model-training-policy) for details.
