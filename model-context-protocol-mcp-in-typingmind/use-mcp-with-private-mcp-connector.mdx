The Private MCP Connector is a self-hosted intermediary that bridges your TypingMind browser session to MCP servers running locally on your device or on a private server. You need this when the MCP server can't be reached directly from the browser — for example, a local filesystem server, a Docker-based tool, or any MCP server accessible only within your local network. This guide covers both standard HTTP setup and HTTPS setup (required for browsers like Safari).

<Note>
  The Private MCP Connector is only needed in the **Personal version** of TypingMind. The Team version handles MCP server connections differently.
</Note>

## What is the Private MCP Connector?

The connector is an npm package (`@typingmind/mcp`) that you run in a terminal. It creates a local server that TypingMind communicates with over `localhost`. The connector then forwards tool calls to whichever MCP server commands you configure — such as `npx @modelcontextprotocol/server-filesystem` or any other MCP-compatible command.

The package is open source and available at [npmjs.com/package/@typingmind/mcp](https://www.npmjs.com/package/@typingmind/mcp).

## Prerequisites

- **Node.js** installed on your machine (LTS version recommended). Download from [nodejs.org](https://nodejs.org/en).
- A terminal application.

## Set up the connector (standard HTTP)

<Steps>
  <Step title="Open MCP settings in TypingMind">
    Go to **Settings** in the left workspace bar. Under **Advanced Settings**, click **Model Context Protocol**.
  </Step>
  <Step title="Click Setup MCP Connector">
    Click the **Setup MCP Connector** button. A dialog will appear.
  </Step>
  <Step title="Select This Device">
    In the "Setup MCP Connector" dialog, select **This Device** and click **Next**.
  </Step>
  <Step title="Copy the connector command">
    TypingMind will display a command like:

    ```shell
    npx @typingmind/mcp [auth_token]
    ```

    Copy this command. The `[auth_token]` is a unique token generated for your session.
  </Step>
  <Step title="Run the command in a terminal">
    Open a terminal window and paste the command. Press Enter to start the connector. Leave this terminal window open while using TypingMind.
  </Step>
  <Step title="Confirm connection in TypingMind">
    Once the connector starts, the TypingMind interface will show **Server Ready**. Click **Get started** to proceed.
  </Step>
</Steps>

## Add local MCP servers to the connector

With the Private MCP Connector running, you can connect to any local MCP server by adding it through the MCP Store interface in TypingMind as a custom connector, using `localhost` as the server address.

Refer to the documentation of your specific MCP server for the command to run it. Common examples:

```shell
# Filesystem server (access local files)
npx @modelcontextprotocol/server-filesystem /path/to/directory

# GitHub server
npx @modelcontextprotocol/server-github

# Any MCP-compatible server via uvx
uvx mcp-server-name
```

## Set up HTTPS for the connector (required for Safari)

Some browsers, including Safari, require HTTPS even for localhost connections. The following steps walk you through generating a locally-trusted certificate and running the connector with HTTPS enabled.

### Phase 1: environment setup

<Steps>
  <Step title="Verify Node.js is installed">
    Open a terminal and run:

    ```shell
    node -v
    ```

    You should see a version number (for example, `v20.12.2`). If not, download and install Node.js from [nodejs.org](https://nodejs.org/en).
  </Step>
  <Step title="Install Homebrew">
    Homebrew is a package manager for macOS that installs tools like mkcert.

    Go to [brew.sh](https://brew.sh/) and run the install command shown on the page:

    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    ```

    Follow the on-screen prompts. After installation, verify it works:

    ```shell
    brew --version
    ```
  </Step>
  <Step title="Install mkcert">
    `mkcert` creates locally-trusted development certificates that your browser will accept.

    ```shell
    brew install mkcert
    ```

    If you use Firefox, also install the network security services library:

    ```shell
    brew install nss
    ```
  </Step>
  <Step title="Generate a local certificate">
    Install the mkcert certificate authority into your system's trust stores (run once per machine):

    ```shell
    mkcert -install
    ```

    Then generate a certificate for `localhost`:

    ```shell
    mkcert localhost
    ```

    This creates two files in your current directory:
    - `localhost.pem` — the certificate
    - `localhost-key.pem` — the private key
  </Step>
</Steps>

### Phase 2: run the connector with HTTPS

<Steps>
  <Step title="Get the connector command from TypingMind">
    Follow the standard setup steps above to get the `npx @typingmind/mcp [auth_token]` command from TypingMind. **Do not run it yet.**
  </Step>
  <Step title="Modify the command to use your certificates">
    In the same terminal directory as your `.pem` files, run the modified command with certificate paths prepended:

    ```shell
    CERTFILE=./localhost.pem KEYFILE=./localhost-key.pem npx @typingmind/mcp [auth_token]
    ```

    Replace `[auth_token]` with the actual token from TypingMind (copy the full command from the TypingMind dialog to get the correct token).

    **What each environment variable does:**
    - `CERTFILE=./localhost.pem` — path to the certificate file
    - `KEYFILE=./localhost-key.pem` — path to the private key file
  </Step>
  <Step title="Confirm the connector is running">
    Once started, you'll see output in the terminal confirming the server is live over HTTPS. In TypingMind, the status will change to **Server Ready**.

    Click **Get started** to begin using the connector.
  </Step>
</Steps>

<Warning>
  Keep the terminal window open the entire time you're using the Private MCP Connector. Closing the terminal stops the connector and breaks the connection.
</Warning>

## Troubleshooting

**TypingMind shows "Connector not found" or the connection doesn't establish:**
- Make sure the terminal is still running the connector command.
- Check that you used the correct auth token from TypingMind.
- Restart the connector by stopping it (`Ctrl+C`) and running the command again.

**Safari rejects the connection as insecure:**
- Follow the HTTPS setup steps above. Safari requires HTTPS even for localhost connections.

**"Certificate not trusted" error in the browser:**
- Make sure you ran `mkcert -install` to add the certificate authority to your system trust store.
- Restart your browser after running the install step.

**The connector starts but MCP tools don't appear in TypingMind:**
- Verify that the MCP server command you configured is correct and that the server starts without errors.
- Check the terminal output from the connector for any error messages.
