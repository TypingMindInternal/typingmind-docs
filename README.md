# TypingMind Docs

This is the official documentation for [TypingMind](https://www.typingmind.com)

## What is TypingMind?

**TypingMind** is designed for people who want more control and flexibility when working with AI. It brings different models into one place and adds a more powerful workspace for chatting, organizing conversations, saving prompts, building AI agents, connecting plugins, and working with your own knowledge base.

This documentation covers everything you need to get started and go deeper with TypingMind, including model setup, AI Agents, plugins, MCP, RAG, prompt management, chat organization, and more!
