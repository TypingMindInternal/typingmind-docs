## Which Plan Should You Choose?

- **Standard** — Great if you just need the core chat features to get started.
- **Extended** — Everything in Standard, plus additional plugins like Web Search and Dall-E.
- **Premium** — Everything in Extended, plus access to all plugins, advanced features like Artifacts, Project Folders, and Canvas Editor.
