## **Do I need an OpenAI API key to use Typing Mind on Setapp?**

→ No. You don't need an OpenAI API key. Setapp provides free models (GPT-3.5 and GPT-4) for free. Optionally, you can choose to enter your own API key and use it instead.

## **Why does the assistant say it's not GPT-4 when I ask it which model it is running on?**

→ It is a well-known fact that the GPT-4 model doesn't know about itself. This is because it has a knowledge cutoff date, and GPT-4 didn't exist when it was trained.

## **Is there a free Claude model provided by Setapp?**

→ Not yet, but we are looking to provide this soon.

## **Why do I see an error with limits all the time? ("OpenAI has rejected your request with error code 429")**

→ The free Setapp models (GPT-3.5 and GPT-4) come with some limitations. See here: [https://support.setapp.com/hc/en-us/articles/9165363863068-Limitations-in-Setapp-apps](https://support.setapp.com/hc/en-us/articles/9165363863068-Limitations-in-Setapp-apps)

## **I have a Setapp subscription. Can I use Typing Mind via the web with the Setapp free models?**

→ No. The Setapp free models and its premium features are only accessible via the macOS app in Setapp.
