# Added OAuth 2.0!

### **🚀 What's New?**

Added OAuth 2.0 to [custom.typingmind.com](http://custom.typingmind.com/) 😄

Now you can integrate with ANY OAuth 2.0 provider so your users can log in more easily.

👋 Go to Admin Panel → User Management → Authentication → OAuth 2.0 to set up.
