### **🚀 What's New?**

Big feature release: Chat Logs 💬

You can enable chat logs for your chat instance in Typing Mind Custom:

✅ Disabled by default (Private Mode)
✅ Enable only for anonymous users
✅ Enable for all users

Super helpful to review and improve the prompts from the chat history!
