### **🚀 What's New?**

🥳 GREAT NEWS: Train AI Characters with your custom data on [http://custom.typingmind.com](http://custom.typingmind.com/)!

Simply:

- Add tags to your training docs
- Assign these tags to certain AI characters so it can access certain training docs linked with that tags.

This allows you to:
🤖 Make use of AI characters to build multiple chatbots
💻 Easily control user access to each chatbot
