✅ We’ve updated a new plugin on TypingMind: **Mermaid diagram**

### **🚀 What's New?**

**Mermaid Diagram:** New Plugin on [typingmind.com](http://typingmind.com/).

- This plugin helps you generate and render diagrams using the Mermaid.js library.
- This can be used to render various types of diagrams, including Flowchart, Sequence Diagram, Class Diagram, Mind Map, Gantt Chart, etc.

To learn how to use plugin on TypingMind, refer to this: https://docs.typingmind.com/plugins/how-to-use-typingmind-plugin
