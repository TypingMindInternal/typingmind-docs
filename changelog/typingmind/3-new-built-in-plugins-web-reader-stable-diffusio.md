# 3 new built-in plugins: Web Reader, Stable Diffusion Image, Market News

### **🚀 What's New?**

**Added 3 new built-in plugins:**

- Stable Diffusion Image: generate images similar to DALL-E plugin. Powered by StabilityAI API.
- Web Page Reader: read content of web URLs.
- Market News: get news from stock/crypto market. Powered by Alpha Vantage API.
