title: "Set up OAuth 2 Authentication for TypingMind plugins"
---
🟢 TypingMind Plugins now support OAuth 2.0 authentication! 

This means you can now create plugins that use the user's account to authenticate instead of your fixed API key. 

This authentication type makes it easy to work with external services that require OAuth.

### **🏁 How it works**

👉To help you set up OAuth in your plugin: we've prepared a comprehensive guide: https://docs.typingmind.com/plugins/oauth-for-plugin
