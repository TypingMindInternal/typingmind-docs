# Set up Local Whisper

Set your local Whisper endpoint for voice input on [http://typingmind.com](http://typingmind.com/)!

## **🏁 How it works**

- Go to Settings
- Select Proxy & Org ID
- Change the OpenAI Whisper Endpoint to your local endpoint.
