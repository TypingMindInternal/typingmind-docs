# API Key encryption

### **🚀 What's New?**

Added API Key encryption to [typingmind.com](http://typingmind.com/). It’s safer!!!

If you're really concerned about leaking your API key, you can set a password and encrypt your key when it's stored on your local device.

Note: you'll have to enter the password every time you open/refresh the app
