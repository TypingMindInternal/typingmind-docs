TypingMind is updated regularly with new AI model support, features, and improvements. This page summarizes the most notable changes across recent releases.

<Note>
For the full detailed changelog, visit [typingmind.com/changelog](https://typingmind.com).
</Note>

## Recent highlights

### MCP (Model Context Protocol) support
TypingMind now supports connecting to any MCP-compatible server — including popular services like GitHub, Figma, Supabase, Slack, Zapier, and more. Use the **MCP Store** in the Plugins panel to browse and connect servers, or add custom connectors manually.

### Google Gemini 2.5 Pro & Flash
Support for Gemini 2.5 Pro and Gemini 2.5 Flash — including Gemini's long-context capabilities (up to 1M tokens) and native multimodal inputs.

### OpenAI GPT-4.1 and GPT-5
Added support for OpenAI's latest models including GPT-4.1 and GPT-5, with full function-calling and vision support.

### Moonshot AI (Kimi K2)
Added native support for Moonshot AI's Kimi K2 model via the custom model connector.

### Deep Research plugin
A new Deep Research plugin combines web search with intelligent synthesis to produce comprehensive research reports on any topic.

### GPT Image Editor
The GPT Image Editor plugin brings OpenAI's image editing capabilities directly into your TypingMind chats — generate, edit, and iterate on images inline.

### Chat Threads
When you regenerate or edit a message, TypingMind now preserves both versions as separate threads. Switch between threads to compare or continue any version.

### Project Folders
Projects give each workspace a dedicated context — assign a specific AI model, write custom system instructions, and attach relevant documents so every chat in the project starts with the right setup.

### Multi-agent workflows
Build chains of AI agents that hand off to each other using the `@[AgentName]` mention syntax. Orchestrate complex, multi-step tasks across specialized agents.

### Prompt caching
Prompt caching reduces costs and speeds up responses for Claude, OpenAI, and Google Gemini models by reusing context from recent prompts. Enable it in Parameter Settings.

### TypingMind Team analytics
Workspace admins can now view usage analytics per user — including message counts, model usage, and token consumption — to understand how the team is using AI.

### Canvas editor
Edit AI-generated text or code directly in a side-by-side canvas. Rewrite sections, adjust tone, apply markdown formatting, and make changes without breaking the conversation flow.
